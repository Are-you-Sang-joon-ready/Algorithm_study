## 🚀 참여 방법

1. 이 저장소(Original Repository)를 **Fork** 합니다.
2. Fork한 개인 저장소에 **자신의 GitHub ID** 혹은 **이름**으로 폴더를 생성합니다.
   - ⚠️ *주의: 폴더명에 콜론(`:`)은 사용하지 말아주세요!*
3. 생성한 폴더 내부에 개인 소스코드를 업로드합니다.
4. 아래 **Commit 규칙**을 지켜 커밋을 작성합니다.
5. 원본 저장소로 **Pull Request(PR)**를 보냅니다.
   - 📅 **매주 3문제 이상** 풀이 권장 [굳이 안그래도 됨]
   - 📅 **매주** 보이면 수시로 merge 함.
6. 다른 사람들의 PR을 보고 자유롭게 코드 리뷰를 진행해 주세요!

> ⚠️ **주의사항**: 기존에 등록된 타인의 폴더를 지우면 안 됩니다! 오직 본인의 개인 폴더 내부만 수정 및 추가해 주세요.
> 💬 **디스코드**: 디스코드 채널에 모르는 질문도 언제든 환영합니다!

## ✅ commit 규칙
- commit 메세지: [문제출처] 문제번호 / 난이도 / 문제 걸린시간 / 이름
- description: 문제 주소 (option)
- 터미널에서 작성법: 
```
git commit -m "[PGS] 예시제목 / 레벨2 / 1분 / 나상준" 
```
- 플랫폼 작성법 통일:  
  * [PGS] - 프로그래머스
  * [SEA] - 삼성SW Expert Academy
  * [LTC] - 리트코드
  * [CFS] - 코드포스
  * [ETC] - 그외

## ✅ PR 규칙
- PR 제목: [문제출처] 문제번호 / 문제 레벨(등급) / 문제 걸린시간 / 이름
-  ```[PGS] 42586 / 레벨2 / 40분 / 나상준 ```
-  comment는 편하신대로 작성하면됩니다. 간단한, 알고리즘 방식이나, 풀었던 것에 대한 회고 정도 남겨주시면 
감사하겠습니다.
